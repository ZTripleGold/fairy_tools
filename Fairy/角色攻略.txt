# 星见雅（S级·烈霜·异常）

+ **角色定位**：星见雅是烈霜属性S级异常代理人，首位「虚狩」级角色。她定位为**站场输出型主C**，拥有独特的烈霜属性（可与冰属性相互触发紊乱），输出核心为通过积攒 **「落霜」** 点数释放高倍率三段蓄力斩击，兼具直伤与异常爆发能力。操作简便、配队灵活，是版本T0级主C。

- **核心机制**：
  - **烈霜属性**：与冰属性共享加成，可相互结算触发**紊乱**，大幅提升配队灵活性。
  - **「冰焰」与异常效率**：造成烈霜伤害时为敌人施加 **「冰焰」** 。对附有冰焰的敌人积累烈霜异常时，根据星见雅**暴击率**等比提升异常积蓄效率（80%暴击率吃满）。
  - **「霜灼·破」**：触发烈霜异常时，消除冰焰造成高倍率 **「霜灼·破」** 伤害（可暴击），并获得1点 **「落霜」** （10秒内最多1次）。同时敌人进入 **「霜灼」** 状态，全队对其异常积蓄效率+20%，但雅无法再施加冰焰（鼓励切人打紊乱）。
  - **「落霜」与蓄力爆发**：「落霜」点数上限6点，通过强化特殊技（+2）、终结技（+3）、队友触发紊乱（+2）等方式获取。攒满6点后可释放**三段蓄力普攻「霜月架势」**，造成**4282.8%** 超高倍率伤害（12级），并享受额外能力60%增伤和30%无视冰抗。
  - **额外能力**：队伍有支援或对空六课角色时触发，蓄力普攻伤害+60%；队友触发紊乱时，雅获得2点落霜，且下一次蓄力普攻无视目标30%冰抗。
  - **输出循环**：站场打异常→触发「霜灼·破」→切队友打紊乱（为雅回豆）→切回雅强化特殊技+三段蓄力，循环往复。
- **驱动盘/音擎**：
  - **四件套**：**「折枝剑歌」**（首选，暴伤+16%，冻结/碎冰后额外+20%暴击率，霜灼状态可触发）。
  - **二件套**：**「啄木鸟电音」**（补暴击率，优先确保80%阈值）。
  - **主词条**：4号位：**暴击率/暴击伤害**；5号位：**冰伤/穿透率**；6号位：**异常掌控**。
  - **副词条**：**暴击率（≥80%）  暴击伤害  攻击力%**。需优先保证80%暴击率以吃满异常效率加成。
  - **音擎**：专武 **「霰落星殿」**（首选，提供暴击率、暴伤、冰伤，完美契合）；备选 **「双生泣星」**。

  - **二件套**：**「激素朋克」**（优先补攻击力，帮助达到3400阈值）/ **「震星迪斯科」**（攻击力达标后补冲击力）/ **「摇摆爵士」**（补能量回复）。

# 爱芮（S 级·以太·异常）

## 角色定位

爱芮是一位主打失衡爆发的以太属性 S 级异常主 C 代理人，来自虚拟偶像团体「妄想天使」。战斗中，爱芮可通过蓄力攻击触发核心机制【异放】，对异常状态敌人额外结算高额属性异常伤害，失衡期间【异放】伤害还会获得巨额提升；同时可通过多种招式生成【应援能量】，实现连续蓄力攻击的无缝爆发循环。她的终结技可开启【以太帷幕?妄想重奏】为全队提供攻击力增益，与同团角色千夏形成完美联动。爱芮操作门槛低、爆发循环顺滑，不刚需双异常队友，在应对精英和首领敌人的失衡爆发场景表现极为优异。

## 核心机制

### 核心爆发【异放】

爱芮的核心输出手段，第三段蓄力普攻【绝对音准】重击命中处于**任意属性异常状态**的敌人时，触发一次【异放】，额外结算一次对应属性的异常伤害。该伤害结算比例与爱芮自身异常掌控直接挂钩，每 10 点初始异常掌控可提升对应异常的结算比例；**目标处于失衡状态时，异放伤害比例额外提升 50%**，是爱芮的爆发核心。

### 核心循环资源【应援能量】

爱芮的普攻第四段、特殊技、强化特殊技、连携技、快速支援、队友开启【以太帷幕】等招式，均可在场上生成【应援能量】，最多可储存 8 个。爱芮蓄力攻击时会自动吸收附近的【应援能量】，每吸收 1 个可直接提升 1 段蓄力等级，无需原地长按等待蓄力，实现连续第三段蓄力攻击的无缝循环，大幅简化爆发操作，保证输出节奏。

### 爆发强化【妄想时刻 / 以太帷幕·妄想重奏】

# 南宫羽（S 级?以太?击破）

## 角色定位

南宫羽是**妄想天使队长**，主打**速切击破 + 异常增伤 + 失衡掌控**的以太属性 S 级击破代理人，也是当前版本异常队的核心辅助击破位。输出辅助两手抓，既能通过**精准蓄力**实现高额失衡值快速积蓄，为队伍创造稳定爆发窗口；又能提供全队增伤、失衡易伤、延长失衡时间，还可触发【异放】【极性紊乱】补充伤害，适配妄想天使体系及各类异常 / 强攻队。操作门槛适中，失衡效率独一档，无需复杂轴件即可实现稳定循环，是兼顾功能性与输出的全能击破角色。

**省流**：功能拉满的全能击破，快失衡、强增伤、补伤害，妄想天使体系核心拼图，适配绝大多数异常队 / 强攻队。

## 核心机制

### 核心资源【重拍】

南宫羽的核心循环资源，是触发多段蓄力攻击的基础，数值规则严格绑定实战操作：

1. **基础数值**：上限 100 点，进入战场初始拥有 30 点，接战状态下**每秒自然回复**；
2. **快速回复**：队伍中任意角色使敌人进入异常状态时，额外回复重拍（每 6 秒最多触发 1 次），异常配队下回转极快；
3. **消耗规则**：二段 / 三段蓄力攻击**各消耗 50 点重拍**，是触发高失衡值的核心消耗方式。

### 核心被动【天才偶像】

南宫羽的属性收益核心，直接决定失衡效率与辅助能力：

1. 异常精通无条件提升，**异常掌控超过阈值后，每 1 点超额掌控同比例转化为冲击力**，6 号位带异常掌控收益近乎冲击力的两倍；
2. 普攻 / 强化特殊技命中敌人时，**自身异常积蓄效率 + 失衡值提升**，同时为全队提供增伤 buff（重复触发刷新持续时间）；
3. 敌人失衡时，队伍任意角色触发【异放 / 紊乱 / 异常状态】，均可为敌人积累 1 层【颤音】（单目标最多 4 层）。

### 核心增伤 / 补伤【颤音】

失衡期核心伤害补充机制，与异放深度绑定：

1. 颤音叠满 4 层，或持有颤音时敌人从失衡恢复，会清除所有颤音并**触发 1 次高额异放**（敌人需处于异常状态）；
2. 异放伤害随清除的颤音层数提升，**同一次失衡内敌人仅可被施加 1 次颤音**，需精准把控触发时机。

### 核心失衡手段【精准蓄力】

南宫羽独有的高额失衡核心，操作简单但收益极高：

1. 长按普攻触发蓄力攻击，**南宫羽翅膀闪光瞬间松开按键**，即可触发精准蓄力，**招式失衡值提升 20%**；
2. 蓄力攻击分 3 段，**连携技 / 终结技 / 强化特殊技后，重拍充足可直接跳过一段，长按触发二 / 三段蓄力且必定精准蓄力**（核心手法 EAAA 的底层逻辑）；
3. 蓄力机制附带生存保障：一段蓄力抗打断提升 + 减伤 60%，二段 / 三段蓄力期间无敌，一段冲刺阶段格挡成功也视为精准蓄力；**所有攻击动画期间均无敌，仅蓄力过程非无敌**。

## 核心输出手法

南宫羽实战逻辑简单，核心围绕**精准蓄力 + 速切循环**，关键是**用三段蓄力 / 终结技施加踉跄，再切主 C 爆发**，需少量练习精准蓄力时机，排轴则根据自身失衡效率调整：

### 通用基础循环（非失衡期?攒资源 / 压失衡）

1. 速切南宫羽进场，释放**强化特殊技（E）**，触发全队增伤 + 重拍回复；
2. 长按普攻触发**精准蓄力**，打二段 / 三段蓄力攻击（根据重拍数量），积累敌人失衡值；
3. 打完一套蓄力后速切队友，补充 buff / 输出，等待重拍回复后再次切回南宫羽循环，**核心手法为 EAAA**（强化特殊技 + 三次普攻衔接蓄力）。

### 爆发循环（失衡期?核心窗口）

1. **铺垫**：用南宫羽**三段蓄力重击 / 终结技**将敌人打入失衡，确保施加**踉跄**效果（失衡易伤 + 30%+ 时间 + 3 秒）；
2. **爆发**：立即切主 C（爱芮 / 星见雅 / 爱丽丝等），释放连携技 + 终结技，打满失衡期爆发；
3. **补伤**：主 C 输出间隙，可切回南宫羽，利用**舞力全开**触发极性紊乱，补充伤害并触发队友快速支援，最大化失衡窗口收益。

### 操作优化

1. 开启**手动连携**，避免失衡期误触连携技打断输出；
2. 牢记精准蓄力时机：**南宫羽进入蓄力动作后，翅膀闪光瞬间松普攻**，无需长按，练习后可 100% 触发；
3. 记录自身南宫羽一轮蓄力的失衡值，根据怪物失衡条厚度排轴，确保**用南宫羽的三段蓄力 / 终结技完成最后一击打入失衡**，稳定触发踉跄；
4. 妄想天使队中，南宫羽三段蓄力会触发**协同攻击**，伤害 + 失衡倍率均提升，优先打满三段蓄力。
